# 서울시 전기차 보급 요인 EDA

팀 "데이터다목조" EDA 과제 · 공공데이터로 **무엇이 서울시 전기차 보급과 관련 있는지** 세 가지 가설을 검증했습니다.

| 가설 | 노트북 | 데이터 | 결과 |
|---|---|---|---|
| **유가가 오르면 3개월 뒤 전기차 신규 등록이 늘어난다** (담당: 이성진) | [유가와전기차](데이터다목조_eda최종제출/분석코드들/유가와전기차.ipynb) | 오피넷 서울 월별 유가(22.1~24.12), 서울시 차량 등록현황(22.3~25.3) | Pearson r = 0.33 (p = 0.049), R² = 0.11 |
| 소득 수준이 높은 구일수록 전기차 비율이 높다 | [소득수준과전기차](데이터다목조_eda최종제출/분석코드들/소득수준과전기차.ipynb) | 구별 1인당 건강보험료, 차량 등록현황 | R² = 0.53 → 강남구 제외 시 0.34 |
| 충전기가 많은 구일수록 전기차 보급률이 높다 | [충전소와전기차](데이터다목조_eda최종제출/분석코드들/충전소와전기차.ipynb) | 한국환경공단 충전소 정보, 차량 등록현황 | Pearson r = 0.44 (p = 0.027), 강남구 제외 시 0.65 |

## 유가 → 전기차 신규 등록 (개인 담당)

1. **유가 전처리**: 휘발유·경유 월평균을 합쳐 평균 유가를 만들고, 구매 결정에서 등록까지의 시차를 고려해 **3개월 뒤 등록 월**과 매칭
2. **전기차 전처리**: 월별 엑셀 파일들을 파일명에서 연월을 뽑아 하나로 합친 뒤, 누적 등록 대수의 차분으로 **월별 신규 등록**을 계산
3. **검정**: Pearson(선형)과 Spearman(순위) 상관을 함께 확인하고, 이중 축 그래프와 회귀선으로 시각화

**해석**: 피어슨 상관은 유의수준 경계(p = 0.049)에서 유의했지만 스피어만은 유의하지 않았고(p = 0.155), 유가가 신규 등록 변동을 설명하는 비율은 약 11%에 그칩니다. 2023년 1~2월처럼 신규 등록이 급감하는 구간도 유가로는 설명되지 않아, **실제 구매는 보조금 같은 정책 요인의 영향이 더 클 것**으로 해석했습니다.

개인 작업본: [이성진.ipynb](이성진.ipynb)

## 공통 발견

소득·충전소 가설 모두 **강남구 하나가 결과를 크게 좌우**했습니다. 강남구를 빼면 소득 가설의 설명력은 절반 가까이 떨어졌고, 충전소 가설은 오히려 상관이 강해졌습니다. 구 단위 표본이 25개뿐이라 이상치 하나의 영향이 크다는 점을 확인하고 두 경우를 함께 보고했습니다.
